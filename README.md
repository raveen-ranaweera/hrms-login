# HRMS Login Dashboard

A modern Human Resource Management System (HRMS) with login, dashboard, and attendance tracking features.

## Features

- 🔐 User Authentication & Authorization
- 📊 Admin, Manager & Employee Dashboards
- ⏰ Real-time Attendance Tracking (Check-in/Check-out)
- 📅 Leave Management System
- 💰 Salary & Payroll Overview
- 🎨 Responsive Design with Dark Mode Support
- 📱 Mobile-Friendly Interface

## Tech Stack

- **Frontend:** React 18 + Vite
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Routing:** React Router DOM
- **State Management:** React Context API
- **Build Tool:** Vite
